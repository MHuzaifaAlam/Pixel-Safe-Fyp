## Getting Started

### 1️⃣ Clone the repository

```bash
cd Pixel-Safe-FYP
cd backend
python3 -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows (Command Prompt)
venv\Scripts\activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1

pip install -r requirements.txt
```
